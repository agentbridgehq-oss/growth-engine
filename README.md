# Growth Engine

Niche-to-revenue system mapped from the 2026 Marketing Playbook.

## The Machine (six handoffs)
1. Short video — earn the stop
2. Keyword comment — signal intent
3. Instant DM — deliver now
4. Email capture — own the audience
5. Checkout — remove friction
6. Follow-up — recover + expand

## Meridian Mapping
- Video: agent answering a real call, mid-ring open, 30s
- Comment: AGENT + typo variants
- DM: demo link via Stan AutoDM (24h Meta window)
- Capture: Kit free plan
- Checkout: $199 / $499 / $999, middle = Most Popular
- Follow-up: 5-email welcome + 3-email cart recovery

## Scoreboard
Weekly inputs: posts, visits, downloads, clicks, sales.
Diagnose the thinnest handoff. Fix only that one.

## 30-Day Sprint
- Week 1: Offer + proof
- Week 2: Handoffs
- Week 3: Creative tests
- Week 4: Recovery + scale
- Paid traffic gate: organic must prove the offer first

## Stack
- Stan Creator ($29/mo) + AutoDM
- Kit (free → $39/mo)
- Stripe (Meridian tiers)
- Netlify (landing pages)
- X (organic + paid after proof)
